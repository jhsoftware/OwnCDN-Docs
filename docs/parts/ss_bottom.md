
## Requests served

A graph showing the number of requests / bytes served.

Select Period / Type for various graph data.


## Relationships

Shows a map of related services - if the service is the source of another service, and/or if the service is using other services as sources / storage.

The current service is indicated with a gray background.

Click on a related service to go to the Service Status page for that service.


## Edit service (button)

Click this button to edit the service.
