# UI / Services

The page show a list of all the configured services.


## Group by source

When this option is checked, the list below is grouped according to source, so that services that are a source of another service is listed directly under that service (with an arrow-up icon indicating their relationship) - possibly in multiple levels.

Note that a service may be the source of multiple other services, and therefore may appear multiple times in the list when the "Group by source" option is enabled.


## List of services

Click the column headers to sort the list according to service name, type, or HTTP binding.

Click the pencil icon next to each service to edit that service.

Click a service name to go to the [Service status](ss_index.md) page for that service.

Click the "+ New service" button to configure a new service.
